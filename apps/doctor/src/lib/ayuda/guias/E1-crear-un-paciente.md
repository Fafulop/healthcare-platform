# Crear un paciente

**Pasos**
1. **«Expedientes Médicos» → «Nuevo Paciente»**.
2. Obligatorios: **Nombres**, **Apellidos**, **Fecha de Nacimiento**, **Sexo**. Lo demás es opcional (teléfono, email, tipo de sangre, alergias, etiquetas…).
3. **«Crear Paciente»**.

**Qué vas a ver:** el perfil del paciente, con su ID interno generado solo.

**Para editarlo después:** en el perfil, **«Editar»** (Información de Contacto) → cambia → **«Guardar Cambios»**.
