# Abrir una visita

**Para qué:** juntar en un solo lugar lo de un día con el paciente: plantillas, fotos, notas, recetas y ventas.

**Cuándo se abre sola:** al **completar una cita** de un paciente con expediente.

**Pasos — abrirla tú**
1. Perfil del paciente → **«Nueva Visita»**.
2. **«¿De qué cita?»**: elige una cita del paciente o **«Sin cita»** (y la **Fecha**).
3. Si te pregunta **«¿Es seguimiento?»**, deja «No» para una visita suelta.
4. **«Crear visita»**.

**Qué vas a ver:** «Visita del …» con sus secciones: Cita · Plantillas · Fotos y documentos · Notas · Recetas · Ventas · Comentario.

**Borrar una visita:** sólo mientras está vacía, con **«Borrar visita»**.
