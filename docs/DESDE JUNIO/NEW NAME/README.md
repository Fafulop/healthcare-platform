# NEW NAME — buscar marca registrable ante el IMPI

**Estado:** en investigación · **Última actualización:** 2026-07-28

## El problema

La marca actual es **tusalud.pro** y **no es registrable ante el IMPI**.

La razón es el art. 173 frac. XVIII de la LFPPI: se niegan los signos **descriptivos o
genéricos** respecto de los servicios que amparan. "Salud" para una plataforma de salud es
exactamente eso. Además el campo fonético está saturado (decenas de marcas
TuSalud / MiSalud / SaludXXX vivas en clases 42 y 44).

Corolario que aplica a cualquier candidato: **cualquier nombre construido sobre
_salud, med, doc, clínica, care, vida_ hereda los dos problemas** — descriptividad y campo
fonético saturado.

## Qué sí registra

Marcas **arbitrarias o de fantasía**: una palabra real que no tiene nada que ver con el
servicio, o una palabra inventada. Es la posición más fuerte desde la cual se puede solicitar,
y además es lo que hace que una marca se sienta aspiracional en vez de utilitaria.

## Reglas que no se re-litigan

- Trademark y dominio son cosas separadas. `mica.clinic` se puede usar comercialmente hoy sin
  registro de marca; lo que no se tiene sin registro es **exclusividad**.
- Las clases que necesitamos son **42** (software como servicio) y **44** (servicios médicos /
  telemedicina). **Clase 9 no** — esa es para software descargable y aparatos.
- Agregar una palabra descriptiva (`CLINIC`, `SALUD`, `APP`) **no** salva una objeción por
  confusión: el examinador descarta los elementos descriptivos al comparar.
